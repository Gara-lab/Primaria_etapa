# Decisions
- 2026-09-11 Decision: Any tool script that calls one paid vendor for an otherwise-generic creative capability (TTS, SFX gen, music gen, image/thumbnail gen, video-clip gen, avatar gen, transcription) gets that call isolated behind a `PROVIDERS` dict + a `<CAPABILITY>_PROVIDER` env var (default = the vendor that shipped working), per user request to be able to swap vendors without being locked in. Destination-specific integrations (YouTube upload/stats, Notion sync) and intentionally single-vendor tools (bakeoff_clip.py's fal-model comparison harness) were deliberately left un-abstracted — there is no generic alternative to swap for "publish to YouTube," and adding one would be speculative. Remotion/ffmpeg were left untouched as the actual rendering tech, not a swappable ingredient.
